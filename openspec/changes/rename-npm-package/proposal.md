# Proposal

## Why

npm отклонил публикацию `commitlingo` из-за сходства с `commitlint`. Имя `commitlingo-skill` сохраняет бренд и яснее описывает назначение пакета; возможность публикации этого имени пока не подтверждена реестром.

## What Changes

- **BREAKING**: заменить публичное имя npm-пакета и команды установки/обновления на `commitlingo-skill`.
- Согласовать метаданные пакета, lock-файл, executable, npm registry lookup, проверку имени релиза и делегирование обновлений.
- Обновить help, сообщения ошибок, актуальную документацию и проверки.
- Сохранить имя скилла `commitlingo`, репозиторий, расположение пользовательских файлов и гарантии установки.
- Публикация в npm и изменение исторических архивных документов не входят в реализацию.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `skill-installation`: установка и обновление через `npx commitlingo-skill`, согласованное имя npm-пакета во всех этапах получения релиза.

## Impact

Затронуты `package.json`, `package-lock.json`, `lib/installer.js`, тесты установщика и делегирования, проверки упаковки, README и актуальная документация релиза. Новые зависимости не требуются. Версия первого релиза остаётся `0.1.0`; старый npm-пакет не был опубликован, миграционная обёртка не нужна.

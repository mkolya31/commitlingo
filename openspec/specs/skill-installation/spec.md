# skill-installation Specification

## Purpose

Определяет воспроизводимую установку и обновление CommitLingo для Codex в выбранной области с сохранением проектных настроек и пользовательских локалей.

## Requirements

### Requirement: Локальная установка по умолчанию
Команда `npx commitlingo` SHALL устанавливать скилл CommitLingo для Codex только в текущий проект. Глобальная установка SHALL требовать явного флага `--global`.

#### Scenario: Установка без параметров
- **WHEN** пользователь запускает `npx commitlingo` в проекте
- **THEN** скилл устанавливается локально для этого проекта без глобальной установки

#### Scenario: Явная глобальная установка
- **WHEN** пользователь запускает `npx commitlingo --global`
- **THEN** скилл устанавливается глобально для Codex

### Requirement: Обновление имеет отдельную команду и область
Команда `npx commitlingo update` SHALL обновлять только CommitLingo в текущем проекте. Команда `npx commitlingo update --global` SHALL обновлять только глобальную установку CommitLingo. Другие скиллы и установка в другой области SHALL оставаться без изменений.

#### Scenario: Локальное обновление
- **WHEN** установлены локальный и глобальный CommitLingo и другие скиллы, а пользователь запускает `npx commitlingo update`
- **THEN** обновляется только CommitLingo текущего проекта, глобальная установка и другие скиллы не изменяются

#### Scenario: Глобальное обновление
- **WHEN** пользователь запускает `npx commitlingo update --global`
- **THEN** обновляется только глобальный CommitLingo без изменения локальной установки и других скиллов

### Requirement: Пользовательские файлы сохраняются
Установка и обновление CommitLingo SHALL сохранять `.agents/commit-config.json`, пользовательские локали в `.agents/commitlingo/locales/` и `.agents/commitlingo/locale-reviews.json` текущего проекта. Область установки SHALL не подменять общий язык проекта личным глобальным языком.

#### Scenario: Обновление проекта с пользовательской локалью
- **WHEN** проект содержит выбранный язык, пользовательскую локаль и реестр её проверки, а пользователь обновляет скилл
- **THEN** содержимое этих пользовательских файлов сохраняется

#### Scenario: Глобальный скилл в разных проектах
- **WHEN** глобально установленный CommitLingo используется в двух проектах с разными настройками языка
- **THEN** каждый проект использует собственную настройку и пользовательские локали

### Requirement: Версии пакета и скилла согласованы
Каждая версия npm-пакета CommitLingo SHALL устанавливать соответствующую версию скилла из стабильного релиза, привязанного к конкретному Git commit SHA. Повторная установка этой версии SHALL воспроизводить релизное содержимое независимо от последующих изменений основной ветки.

#### Scenario: Установка известного релиза
- **WHEN** устанавливается определённая стабильная версия npm-пакета CommitLingo
- **THEN** устанавливается соответствующая версия скилла из зафиксированного релизного Git SHA

#### Scenario: Основная ветка изменилась
- **WHEN** после выпуска релиза в основной ветке появились новые изменения и пользователь повторно устанавливает прежнюю версию пакета
- **THEN** устанавливается содержимое прежнего релиза, а не новое содержимое основной ветки

### Requirement: Обновление выбирает последний стабильный релиз
Команда `update` SHALL переводить установку на последний стабильный релиз CommitLingo, сохраняя согласованность целевых версий npm-пакета и скилла. Предварительные версии SHALL не устанавливаться автоматически.

#### Scenario: Доступны stable и prerelease
- **WHEN** опубликован стабильный релиз и более новая предварительная версия, а пользователь запускает `update`
- **THEN** целевой версией становится последний стабильный релиз без автоматической установки предварительной версии

#### Scenario: Обновление запускается старой обёрткой
- **WHEN** установленный скилл и запускающая обновление обёртка относятся к старому релизу, а доступен новый стабильный релиз
- **THEN** обновление приводит к согласованной целевой паре версий пакета и скилла нового стабильного релиза, сохраняя выбранную область и пользовательские файлы
